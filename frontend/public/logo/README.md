# KYRO logo assets

Drop this `logo` folder into `frontend/public/`.

Files:
- `kyro-logo-dark.svg/png` — icon-only botanical mark for dark mode
- `kyro-logo-light.svg/png` — icon-only botanical mark for light mode
- `kyro-icon-dark.svg/png`
- `kyro-icon-light.svg/png`
- `favicon-dark-16.png`, `favicon-dark-32.png`
- `favicon-light-16.png`, `favicon-light-32.png`

The SVGs are self-contained SVG files with transparent backgrounds and embedded
high-resolution artwork, so they can be used directly with `<img src="...">`
or as static public assets.

No KYRO wordmark/text is included, per the requested logo-only version.
